Mineflayer Kitbot

A simple kitbot for 6b6t made with Mineflayer.
Features

    Automatically logs into the server
    Delivers kits to whitelisted players
    Easy setup
    Simple and lightweight

Requirements

    Node.js 26.9.0
    Mineflayer
    minecraft-data
    mineflayer-pathfinder

Quick Start

git clone https://github.com/ExploitedTux/6b6t-KitBot.git
cd 6b6t-KitBot
npm install

configure kitbot.js for your bot
node kitbot.js

Configuration

Add your usernames to the whitelist and configure the bot account in kitbot.js.

Important

    The kitbot needs to be near chests containing shulkers.
    There needs to be a respawn point near the chests that the bot can respawn at.
